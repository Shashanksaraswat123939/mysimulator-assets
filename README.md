# mysimulator-assets
Original, code-generated 3D assets for the My Simulator racing game: F1-style cars in 11 fictional team liveries with active-aero
flaps, safety and medical cars, jointed pit-crew models, pit equipment, pit lane / garages / signal gantry, flags, overtake board,
start lights and trackside furniture.

Everything is built by `scripts/build_all.py` (Blender data API) and rendered on GitHub Actions. No third-party assets are included.
